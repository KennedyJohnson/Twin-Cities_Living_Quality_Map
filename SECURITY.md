# Security Policy

If you find a security issue in this project, please report it privately via
[GitHub's private vulnerability reporting](https://github.com/KennedyJohnson/Twin-Cities_Living_Quality_Map/security/advisories/new)
rather than opening a public issue. I'll respond as soon as I can.

This project contains no user accounts or private data; it publishes a static
map built from public datasets. The only secret it uses is a Census API key,
stored as a GitHub Actions secret.
